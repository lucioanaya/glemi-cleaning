GLEMI Visual Website Editor

1. Upload/deploy all files in this ZIP to Vercel.
2. In your glemi-cleaning Supabase project, open SQL Editor and run GLEMI-VISUAL-EDITOR-SETUP.sql once.
3. Sign in to admin.html and open Website.
4. The real website appears inside the panel. Tap highlighted text, buttons, form fields, or images.
5. Edit and press Save change. Images are uploaded to the public site-media bucket.
6. "Restore original" removes only that override and shows the original HTML content again.

Existing Appointments, Calendar, Pricing, Users and login are preserved.
